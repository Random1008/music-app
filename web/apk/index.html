NOUVEAU DANS CETTE VERSION

  • « Titres likés », épinglé en tête de la Bibliothèque. Une carte à dégradé avec le nombre de morceaux, avant tous les filtres : un appui ouvre tes favoris.
  • Glisse le mini-lecteur vers le haut pour ouvrir le lecteur plein écran. Un simple appui fonctionne toujours — le geste demande un déplacement franc, donc les boutons lecture/suivant ne le déclenchent jamais par accident.
  • Mix du jour : tes artistes les plus écoutés, un titre de chacun à tour de rôle, dans une seule file d'attente.
  • « Plus de <artiste> » juste en dessous, pour rester dans le même univers.

Ces deux rangées sont construites uniquement à partir de ce que tu écoutes et de tes favoris. Aucun service externe, aucun classement opaque.

INSTALLATION SUR LE TÉLÉPHONE

  1. Télécharge l'APK ci-dessus depuis le téléphone.
  2. Android demandera d'autoriser l'installation depuis cette source (Paramètres → Applis → Accès spéciaux → Installer des applis inconnues).
  3. Ouvre le fichier téléchargé et installe.
  4. Au premier lancement, saisis l'utilisateur et le mot de passe (l'adresse du serveur est déjà pré-remplie).
  5. Autorise les notifications quand Android le demande : c'est ce qui affiche la commande de lecture.
