NOUVEAU DANS CETTE VERSION

  • Clique un album : sa page s'ouvre (pochette, année, durée, titres numérotés) avec Lecture et Aléatoire. Idem pour un artiste.
  • File d'attente : le bouton en haut du lecteur montre ce qui va suivre et permet de sauter directement à un morceau.
  • Favoris : cœur sur la page album et dans le lecteur, plus un onglet Favoris dans la bibliothèque.
  • Historique réparé : l'application déclare maintenant ses lectures à Jellyfin. Sans ça, le serveur ignorait tout ce qui était écouté — donc pas de « Reprendre la lecture », pas de compteur d'écoute.

INSTALLATION SUR LE TÉLÉPHONE

  1. Télécharge l'APK ci-dessus depuis le téléphone.
  2. Android demandera d'autoriser l'installation depuis cette source (Paramètres → Applis → Accès spéciaux → Installer des applis inconnues).
  3. Ouvre le fichier téléchargé et installe.
  4. Au premier lancement, saisis l'utilisateur et le mot de passe (l'adresse du serveur est déjà pré-remplie).
  5. Autorise les notifications quand Android le demande : c'est ce qui affiche la commande de lecture.
