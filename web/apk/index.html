INSTALLATION SUR LE TÉLÉPHONE

  1. Télécharge l'APK ci-dessus depuis le téléphone.
  2. Android demandera d'autoriser l'installation depuis cette source (Paramètres → Applis → Accès spéciaux → Installer des applis inconnues).
  3. Ouvre le fichier téléchargé et installe.
  4. Au premier lancement, saisis l'adresse du serveur, l'utilisateur et le mot de passe.
Adresse du serveur : http://100.64.0.0:8096
Le téléphone doit être connecté au VPN Netbird (comme pour Jellyfin). Le mot de passe n'est pas conservé : seul un jeton d'accès est enregistré.

Pour mettre à jour plus tard : retélécharge l'APK et installe par-dessus — la clé de signature étant constante, aucune désinstallation n'est nécessaire.
